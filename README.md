# 職場小白訓練

給剛進台灣科技業的新人（工程、業務、PM、採購、人資……各種職位）的職場練習題，直接
在瀏覽器裡用，不用註冊。

- **共同基礎**：職場用語、email、會議、團隊內討論、向上管理、跨部門、
  勞動法規（工時、加班費、請假、薪資、離職、競業、營業秘密）、績效與職涯、畫大餅
  ／PUA／慣老闆話術怎麼辨識與自保、真實職場鬼故事
- **台廠線**與**外商線**：兩線互不影響，最後的總測驗兩線都會考

每個單元先讀教材再練習。每次練習從題庫隨機抽 20 題、選項順序打亂，沒做過和答錯的
題目會優先出；關卡測驗答對 90% 算過關。練習進度只存在你這台裝置的瀏覽器裡，換裝
置或清除瀏覽資料就會從頭開始。

## 內容說明

- 題目與說明由 AI 撰寫。法規題附法條原文出處，新聞、官方說明、文章、
  論壇的題目都附原始網址，且出題前用程式下載出處頁面、確認頁面上真的有對應的文
  字。
- 沒有官方出處的不成文規則標為「業界慣例」，各公司做法可能不同。
- 論壇上的故事標為「網友自述，未經查證」。非公眾人物的姓名已移除。
- 勞動法規的數字以製作當時的法令為準（例如 2026 年最低工資）；內容
  不是法律意見，遇到實際爭議請洽各地勞工局或律師。

## 檔案

整個網站就是 `index.html`、`app.js`、`style.css` 和題庫 `data.js`，沒有後端，答
案與解說都寫在 `data.js` 裡。
